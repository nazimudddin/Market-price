# 🛒 বাজার দর | BazarDor

### Your Daily Bangladesh Market Price Guide

**BazarDor (বাজার দর)** is a web application designed to help people in Bangladesh explore daily market prices of essential products. Users can browse products by category, compare current and previous prices, and stay informed about price changes through a simple and user-friendly interface.

## 🚀 Technologies Used

* **Next.js** — React framework for building the web application.
* **React** — For building interactive user interfaces.
* **TypeScript** — For type-safe and maintainable code.
* **Tailwind CSS** — For responsive and modern styling.
* **MongoDB** — For database management.
* **Better Auth** — For user authentication.
* **React Toastify** — For displaying success and error notifications.
* **Moment.js** — For date and time formatting.

## ✨ Key Features

1. **📊 Daily Market Prices**
   Browse the prices of essential products and stay informed about market rates.

2. **🗂️ Category-Based Browsing**
   Explore products by categories such as rice, lentils, and cooking oil.

3. **📈 Price Comparison**
   Compare current prices with previous prices to understand market price changes.

4. **🔍 Sorting and Product Filtering**
   Find products easily by browsing categories and sorting prices from low to high or high to low.

5. **🔐 User Authentication and Profile Management**
   Create an account, sign in using supported authentication methods, and update your profile information.

## 🎯 Project Goal

The goal of BazarDor is to make everyday market price information easier to access, helping consumers make informed purchasing decisions.

## 💻 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* MongoDB database

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd "Bazar Dor"
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file in the project root and configure the environment variables required by your application, including your MongoDB connection string and authentication credentials.

**5. Start the development server**

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the application.
